# Day01-linux-process-monitoring

# Day 01 — Linux Process Monitoring & Server Health

> **Cloud Computing / DevOps Practical Lab — Day 01**

## 🎯 Objective

Identify resource-heavy Linux processes using measurable evidence and automate CPU/memory reporting with Bash.

This practical focuses on understanding how Linux processes consume system resources and how to investigate high CPU usage using standard Linux tools.

---

## 🛠️ Technologies

- Linux
- Bash
- Process Monitoring
- `/proc`
- Git & GitHub

---

## 📚 Commands Practiced

| Command | Purpose |
|---|---|
| `ps` | View running processes |
| `top` | Monitor processes in real time |
| `uptime` | Check system uptime and load average |
| `free` | Check memory usage |
| `pgrep` | Find process IDs by name |
